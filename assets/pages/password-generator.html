How to make a strong password

  1. Pick Password or Passphrase.
  2. Choose the length and character types.
  3. Copy it, then save it in a password manager.

Password tips

  • Use a different password for every account.
  • Longer beats complicated: 16+ characters or a 5-word passphrase.
  • Turn on two-step verification wherever you can.
