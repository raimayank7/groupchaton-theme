Make a QR code for a link, any text, your Wi-Fi network or a WhatsApp chat. Pick colours and download it as PNG or SVG.

How to make a QR code

  1. Pick what the QR code is for: link, text, Wi-Fi or WhatsApp.
  2. Fill in the details. The code updates as you type.
  3. Choose colours and size, then download PNG (for sharing) or SVG (for printing).

Tips

  • Keep a dark colour on a light background so every phone can scan it.
  • Choose “Highest” error correction for printed codes.

Questions

Is it free?

Completely free, with no sign-up, no watermark and no limit on how many times you use it. Light ads keep the site running.

Do the QR codes expire?

Never. The details are inside the code itself, so it works forever.

Is my Wi-Fi password sent anywhere?

No. The code is made on your device.
